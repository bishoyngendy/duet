# Host step: import a Spec Kit spec
The user wrote this feature's spec with Spec Kit (`spec_md`). Convert it faithfully into the JSON schema: the same user stories and priorities, the same requirement ids and wording, every acceptance scenario as an acceptance criterion (AC-001…) linked to its story, success criteria, key entities, edge cases and assumptions. Do not add, drop or reword requirements. `[NEEDS CLARIFICATION: …]` markers go into `needs_clarification`; sections with no field go into `extra_sections`. Use the research only for fields the spec leaves implicit (e.g. the summary).
